# Pesca Shop PMW - Loja de Iscas Artificiais

Este é o site oficial da **Pesca Shop PMW**, uma loja especializada em iscas artificiais de alta performance.

## 🚀 Funcionalidades
- Catálogo interativo de iscas.
- Modal de detalhes com galeria de fotos.
- Carrinho de compras funcional.
- Finalização de pedido via WhatsApp (envia a lista de itens automaticamente).
- Design responsivo (otimizado para celulares).

## 🛠️ Tecnologias
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Phosphor Icons
